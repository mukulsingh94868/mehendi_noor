# Mehndi Noor

A premium, modern, fully responsive single-page website for a Mehndi / Henna
artist. Built as a **static frontend only** — no backend, database, auth, API,
CMS or payments.

## Tech Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS (v3) with shadcn/ui-style components on Radix primitives
- Lucide React icons
- `next/image` + `next/font` (Cormorant Garamond + Inter)

## Getting Started

```bash
npm install
npm run dev      # http://localhost:3000
```

Other scripts:

```bash
npm run build      # production build (fully static / prerendered)
npm run start      # serve the production build
npm run lint       # ESLint (next/core-web-vitals + next/typescript)
npm run typecheck  # tsc --noEmit
```

## Structure

```
src/
  app/            layout, page (composes sections), globals.css
  components/
    layout/       Navbar, Footer
    sections/     Hero, Services, Gallery, About, Packages,
                  WhyChooseUs, Process, Testimonials, FAQ, Contact
    ui/           shadcn/ui components + SectionHeading, DecorativePattern, Logo
  data/           services, gallery, packages, testimonials, faq,
                  navigation, highlights
  lib/utils.ts    cn() + WhatsApp link helpers + contact constants
  types/          shared TypeScript types
public/images/    placeholder artwork (SVG)
scripts/          image generator for the placeholder artwork
```

## Placeholder Content

Everything business-specific is intentionally placeholder and easy to replace:

- **Imagery** — `public/images/*.svg` are original, abstract henna-art
  illustrations generated by `scripts/generate-images.mjs`
  (`node scripts/generate-images.mjs`). Swap them for real photography of the
  same filenames and dimensions.
- **Pricing** — `src/data/packages.ts` uses `₹ ____` placeholders only.
- **Testimonials** — `src/data/testimonials.ts` are clearly marked samples.
- **Contact details / socials** — see `CONTACT` in `src/lib/utils.ts` and
  `siteConfig` / `socialLinks` in `src/data/navigation.ts`.
- **SEO URL** — update `metadataBase` in `src/app/layout.tsx`.

The contact form does not call an API. It builds a pre-filled message and opens
WhatsApp via `buildWhatsAppLink()` in `src/lib/utils.ts`.
